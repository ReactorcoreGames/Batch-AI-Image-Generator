1 Install and run

▾
  • Unzip the download somewhere you can find again — your Documents folder is fine; Program Files is not needed.
  • Double-click Batch AI Image Generator.exe. There is no installer, and Python is not required.
  • Keep guide.md and assets/icon.ico beside the exe — the Help button and the window icon look for them there.
  • Leave the _internal/ folder alone. Moving or deleting it stops the program running.

Windows 10 or 11 and an internet connection. Nothing else.

Start with the free Cloudflare models

They are faster and better than the Pollinations pair, and the Cloudflare signup is free, takes about three minutes and never asks for a payment method. That is step 3, and it is worth doing before your first batch.

Pollinations — the zero-setup backup

If you want an image in the next ten seconds with no account at all, pick Pollinations on the Provider tab and skip to step 5. It works and it costs nothing.

But treat it as a fallback rather than your main lane. Pollinations allows exactly one request at a time per IP address — measured, and an API key does not lift it — which works out at roughly one image every 15–45 seconds. Fine for a handful, unusable for five hundred. Its images are also capped at about 1024×576. Use it to try the program, then move to Cloudflare for real work.

3 Get your two Cloudflare values free · no card

▾

You need two values, not one: an Account ID and an API Token. Both are free. This unlocks the three free Cloudflare models and the rest of the lineup.

  • Account ID — log in at dash.cloudflare.com. It is a 32-character hex string in your dashboard URL, and on the right-hand side of most account pages. Copy it.
  • API Token — go to dash.cloudflare.com/profile/api-tokens → Create Token → use the “Read all resources” template → Continue to summary → Create Token.
  • Copy the token immediately. Cloudflare shows it exactly once.
  • In the program: Provider tab → paste both into the API Keys box → Save Keys → Check Credentials.
Use the “Read all resources” template

Not the Workers AI one. A read-only token does everything this program needs — tested directly, not assumed. Generating an image is a POST, but it is inference: it creates no resource and changes no setting on your account. If the token ever leaks, nobody can alter anything you own with it.

If you validate the token yourself

Check it against /accounts/{account_id}/tokens/verify — not /user/tokens/verify. The second returns 401 on a perfectly valid account token and will send you chasing a problem you do not have. The program's Check Credentials button already uses the right one.

Where the keys live

Saved to credentials.json beside the program, restricted to your Windows user. Never written to config.json, the job database, or any image metadata. Delete credentials.json and config.json before sharing this folder with anyone.

4 Write your prompt file

▾

A plain .txt file, one prompt per line. Blank lines are skipped. That is the entire format — three lines means three images.

a quiet forest clearing at dawn, mist between the trunks
a coastal fishing village under heavy grey rain
a desert highway at noon, heat shimmer over the asphalt

Notepad is enough. test_prompts.txt in the download is a working example you can copy.

The style suffix (optional, but do it)

Rather than repeating your art direction on every line, write it once in the Style Suffix box and the program appends it to every prompt before sending. Dozens of presets ship in the dropdown, and the Preview panel shows exactly what will be sent. test_style_prompt_addon.txt is the example file.

Prompt length differs by about 7× — and truncation is silent

Past a model's limit the end of your prompt is simply dropped. No error, no warning, and nothing in the picture to tell you. The style suffix is what you lose, because it is appended last.

ModelComfortable length
SDXL Lightning, SDXL Base, DreamShaper, Pollinations DreamShaper~300 characters
P-Image, both Krea, both Recraft, both Nano Banana~800 characters
Pollinations FLUX.1 Schnell~1000 characters
FLUX.2 klein 4B / 9B, FLUX.2 pro Preview~2000 characters

So a long, richly detailed prompt is worth writing for the FLUX models and largely wasted on the Stable Diffusion ones — they are not ignoring your detail, they are never shown it. The character counter under the editor grades your longest prompt plus the suffix against the model you picked. Nothing in the program cuts your text: the counter warns, it does not trim.

One wording trap

The word “blurry” produces genuinely blurry images on the stronger models, because they follow instructions well. Say what you actually want: soft focus, atmospheric haze, depth of field. See prompting.md.

5 Run your first batch

▾
  • Provider tab → pick SDXL Lightning. It is free, it is the default, and it is the fastest thing here.
  • Prompts & Style tab → Choose Prompt File… Start with five or ten lines, not five hundred.
  • Choose Output Folder… — pick an empty folder. Images, sidecars, the log and the job database all land there.
  • Optionally pick a Style Preset, and check the Preview panel.
  • Run tab → Dry Run. It lists every job, every filename and the total cost, with zero API calls. Do this every time.
  • Start Batch. Watch the finished / failed / blocked counters.
What you get

Each image is saved as promptfile-linenumber-first_few_words.jpg (or .png), with a .json sidecar recording the original prompt, the final prompt, the model, seed, size, timestamp and estimated cost. Close the program mid-batch and restart later — finished images are skipped, not regenerated.

Testing a style without paying for the whole file

The Generate slider under the preview runs only the first N prompts. Load your real hundred-line file, pull it down to 5, look at the results, then slide back to All — the five already made are reused, not regenerated. A five-image test costs five images.

Failed vs. blocked

Failed is temporary — a timeout, a blip, a rate limit — and is retried automatically. Blocked means the content filter refused the prompt, which arrives as HTTP 200 OK and a completely black image. The program decodes every image and rejects a flat single colour as permanent, so blocked prompts are never retried. Rewrite the wording; retrying identical text gets the same refusal.

Size, briefly

Standard is the default and right for most batches. On the three Stable Diffusion models Standard 16:9 is 1024×576, capped deliberately because those models are trained around 1024px and degrade above it — duplicated structures, drifting geometry, ugly edges. High goes bigger and warns you when it does. On klein 4B, Standard 16:9 is the full 1536×864. The big figure under the dropdowns is always the size you will actually get.

Lane 3 — the AI Gateway models, and loading credit

Same Cloudflare account, same API token, completely different money. You must load credit before any of these will run — until then they refuse the request and the program reports the batch as out of quota.

Three things that surprise people
  • Card only. PayPal appears as an option but is not accepted — a PayPal-only account is turned away after you have gone through the whole flow.
  • The minimum top-up is $10. The field accepts $10 to $50. Not $5, not an arbitrary amount.
  • There is a 5% purchase fee on top. $10 of credit costs $10.50; $100 costs $105. That is Cloudflare's fee, not this program's.

Do it in this order. Going to the credits page first is what makes this confusing: it sends you away to add a card and then back again, and people end up bouncing between pages.

  • Add your card first — open Billing and add a credit or debit card. Do this before you go anywhere near the credits page.
  • Then open the credits page — AI → AI Gateway → Credits, or use the Check credits link beside the model dropdown in the program.
  • Manage / Top-up credits → enter an amount between $10 and $50.
  • Leave auto top-up off unless you want a standing charge on your card.

Credit does not expire, so the $10 minimum is a one-off that lasts: at $5 per 1000 on P-Image, that is 2000 images.

! Before you spend anything the ones that cost real money

▾
A refused prompt on a paid model is still generated and billed

A blocked prompt is a well-formed request. It gets generated, billed, and handed back as a black frame reporting success. Cloudflare also runs a check over the finished image, not just your text, so an ordinary prompt can be flagged on the strength of a frame you never see — military, weapon and combat subjects draw more of these than most.

On a batch this compounds: five hundred prompts sharing one style suffix that trips the filter means five hundred billed refusals, and because each is marked blocked rather than failed, the run finishes and reports itself clean.

So: test new prompt wording on a free model first. SDXL Lightning uses the same content filter and costs nothing to be refused by. Then use the Generate slider to run the first five before committing the other 495.

A paid image is attempted once and never retried — on purpose

On a paid model the image is generated and billed before the response arrives, so a retry is a new charge, not a recovery. The program tries once and fails permanently rather than quietly buying four copies of one image. Free models get three attempts.

Two deliberate exceptions: a 429 rate limit is refused before anything is generated, so it costs nothing and backs off normally; and a download that fails after the image was made is retried, because it is already paid for and retrying is the only way to get it.

Recraft is the one family that bills a bad request

On twelve of the thirteen Cloudflare models a malformed request is refused before anything is generated and costs nothing. Both Recraft models accept it, bill it, and then fail. The program only ever sends sizes from Recraft's own published list and validates them before the batch starts, so you should not be able to trigger this — but it is why Dry Run exists.

Use Dry Run. Every time.

It lists the whole batch, validates every setting against the model you picked, shows the total cost, and makes zero API calls. It is specifically designed to catch the mistakes that would otherwise be expensive.

→ The recommended path

▾
Free Cloudflare SD models → klein 4B → paid, only if you still need to

Prove your prompts and your style suffix on the free models, where a refusal costs nothing. klein 4B is the honest “start here after the free ones” pick — a large jump in quality, roughly 75 images a day free, and under a fifth of a cent each after that. Most people never need to go further. If you do, Krea 2 Medium Turbo is the best of the expensive models for the money.
