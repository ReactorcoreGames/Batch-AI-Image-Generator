First-time setup

Free · no card needed

Six steps to your first batch. Nothing here costs money — you will not be asked for a payment method. Open each step as you reach it, and tick the checklist on the right as you go; it remembers where you got to.

1

Run it

Unzip the download anywhere you can find again — your Documents folder is fine, and Program Files is not needed. Then double-click Batch AI Image Generator.exe.

There is no installer and Python is not required. Leave the _internal folder beside the exe; moving or deleting it stops the program running.

You will see three tabs

Prompts (what to draw) · Provider (which model, and your keys) · Run (go). That is the whole program.

2

Get two free Cloudflare values

You need two values, not one. Both are free, it takes about three minutes, and no payment method is ever requested.

  • Account ID — log in at dash.cloudflare.com. It is the 32-character hex string in the address bar. Copy it.
  • API Token — go to the API tokens page, then Create Token → the “Read all resources” template → Continue to summary → Create Token. Copy it immediately — Cloudflare shows it only once.
Just want to see it work first?

Skip this step entirely. Pick Pollinations on the Provider tab — no account at all. It is much slower (roughly one image every 15–45 seconds), so come back and do this for any real batch.

Why read-only is enough

Generating an image is inference — it creates nothing and changes no setting on your account. If the token ever leaked, nobody could alter anything you own with it.

3

Paste them in, pick a free model

Go to the Provider tab. Paste both values into the API Keys box, click Save Keys, then Check Credentials to confirm they work.

Then set Model to SDXL Lightning — the default, the fastest here at roughly 2–3 seconds per image, and it bills nothing, ever.

Five models are free like this

Three on Cloudflare, plus both Pollinations models. Anything that costs money carries a $ marker in the dropdown, so you cannot pick one by accident.

4

Write a prompt file

A plain .txt file, one prompt per line. Blank lines are skipped. Three lines means three images.

a quiet forest clearing at dawn, mist between the trunks
a coastal fishing village under heavy grey rain
a desert highway at noon, heat shimmer over the asphalt

Notepad is enough. Start with five or ten lines, not five hundred — or just use example_prompts.txt from this folder.

Keep it under ~300 characters on these models

The Stable Diffusion models read only about 300 characters and silently drop the rest — no error, and nothing in the picture to tell you. The character counter in the program grades this for you as you type.

5

Point it at a folder

On the Prompts tab, click Choose Prompt File… and then Choose Output Folder… Pick an empty folder — the images, their metadata, the log and the resume database all land there together.

Optional: pick a Style Preset. It is appended to every prompt, so you write your art direction once instead of on every line, and the Preview panel shows exactly what will be sent.

6

Dry Run, then Start

On the Run tab, click Dry Run first. It lists every job it would create and the total cost, with zero API calls. Get into this habit now — it is what catches an expensive mistake later.

Then click Start Batch. That is it; watch the counters.

That is the whole setup.

Images are saved as promptfile-linenumber-first_few_words.jpg, each with a .json file recording the prompt, model, seed and size. Close the program mid-batch and reopen later — finished images are skipped, never redone.

Two things worth knowing: the Generate slider runs just the first few prompts of a big file, so you can test a style cheaply; and if an image comes back solid black, the content filter refused that prompt — rewrite it rather than retrying.
